# Single Page CV

A clean, semantic single-page curriculum vitae (CV) template built using HTML5 and CSS3. 

## 🚀 Features

* **Semantic HTML5:** Structured thoughtfully using `<header>`, `<main>`, `<section>`, and `<footer>` tags for better accessibility and SEO.
* **Custom Typography:** Styled with the `Barlow Condensed` font family via Google Fonts.
* **Clean Layout:** Centered bordered container layout with clear visual hierarchy using color-coded headings.
* **Actionable Contact Links:** Built-in `tel:` and `mailto:` links for quick communication.
* **Favicon Support:** Includes a custom page icon in the browser tab.

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **Google Fonts** (`Barlow Condensed`)
